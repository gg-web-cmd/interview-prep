# 생기부 면접 준비기

학교생활기록부 PDF를 읽어 **정성평가 4축**(학업역량·진로역량·공동체역량·서사 일관성)으로 판독하고,
기록에서 **면접 후보 문항**을 뽑아 교사가 고르고 고쳐 쓰는 **교사용** 도구입니다.

**바로 쓰기 →** https://gg-web-cmd.github.io/interview-prep/

## 주요 기능

| 기능 | 설명 |
|---|---|
| 학생부 읽기 | PDF를 브라우저 안에서 읽어 성적·세특·창체·행특을 분리 (pdf.js) |
| 4축 판독 | 기록에서 역량별 근거 문장을 찾아 표시 |
| 이수·성적 진단 | 계열별 권장과목 대조, 학년별 성적 추이, 평균 대비 낮은 과목 |
| 문항 설계 | 기록 기반 후보 문항 생성 → 원문 확인 → 선택·수정 |
| AI 보고서 (선택) | Upstage Solar 연동. 3학년은 예상 면접 질문, 1·2학년은 보강 활동 조언 |
| 설치·오프라인 | 앱으로 설치 가능, 인터넷 없이도 동작 (AI 보고서 제외) |

## 개인정보 처리 방식

- **학생 기록은 어디로도 전송되지 않습니다.** 이 사이트는 HTML·JS 파일만 내려주며,
  업로드한 PDF는 각자의 브라우저 메모리 안에서만 처리되고 탭을 닫으면 사라집니다.
- **AI 보고서는 선택 기능입니다.** 교사가 직접 API 키를 넣고, 비식별 처리된 전송 자료를
  눈으로 확인한 뒤 버튼을 눌렀을 때만 해당 AI 제공사로 전송됩니다.
  이름·학교명·교사명·주민번호·전화번호·이메일·주소는 전송 자료에서 제거됩니다.
- API 키·대학 카드·비식별화 규칙은 각자의 브라우저(`localStorage`)에만 저장됩니다.

## 내 컴퓨터에서 실행하기 (인터넷 없이)

1. 이 저장소를 내려받습니다 (`Code` → `Download ZIP`).
2. 압축을 풀고 `실행.bat`을 더블클릭합니다.
3. 브라우저가 열리면 화면 위쪽 **[앱 설치]** 를 누릅니다.

Node.js가 있으면 `server.js`, 없으면 윈도우 기본 PowerShell의 `server.ps1`로 실행됩니다.

## 알아두실 점

- 4축 점수는 평가가 아니라 **기록에 해당 표현이 얼마나 나오는지 센 값**입니다.
  낮은 축은 "학생이 부족하다"가 아니라 "면접에서 물어 확인할 곳"이라는 뜻입니다.
- 판독·문항 생성은 규칙 기반이며 결과는 **참고용 초안**입니다.
  최종 문항은 반드시 교사가 원문을 확인하고 확정해 주세요.
- 대학별 기출은 프로그램이 만들어내지 않습니다. 각 대학 입학처의
  선행학습영향평가 보고서에서 확인한 내용을 직접 입력해 주세요.
- **교사용 도구입니다. 학생에게 링크를 공유하지 마세요.**

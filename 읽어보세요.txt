생기부 면접 준비기 — 설치형 웹앱 (v1.0)
=========================================

■ 처음 쓰실 때

  1. 이 폴더의  실행.bat  을 더블클릭하세요.
  2. 검은 창이 뜨고 브라우저가 자동으로 열립니다. (http://127.0.0.1:8731)
  3. 화면 위쪽 [앱 설치] 버튼 또는 주소창 오른쪽의 설치 아이콘을 누르세요.
  4. 설치가 끝나면 바탕화면/시작 메뉴에 "면접 준비기" 아이콘이 생깁니다.

  설치한 뒤에는 검은 창을 닫아도 됩니다. 아이콘만 눌러 쓰시면 됩니다.


■ 인터넷 없이 되나요

  됩니다. PDF 읽기, 역량 판독, 성적 계산, 문항 생성, 프롬프트 만들기,
  인쇄까지 전부 이 컴퓨터 안에서 처리합니다.

  인터넷이 필요한 것은 [AI 보고서] 탭뿐입니다. (선택 기능)


■ AI 보고서 (Upstage Solar 연동)

  1) 설정 탭 → 제공사 "Upstage · Solar" 선택
     모델은 solar-pro4 (비워 두면 자동)
       ※ solar-pro2·solar-pro3은 2026년 10월 30일 종료 예정이라 쓰지 마세요.
     API 키는 https://console.upstage.ai/api-keys 에서 발급
     API 주소는 보통 비워 둡니다 (기본: https://api.upstage.ai/v1/chat/completions).
       학교·교육청이 따로 안내한 중계 주소가 있을 때만 https:// 주소를 넣으세요.
     → [연결 확인] 버튼으로 키가 맞는지 먼저 테스트하세요.

  2) 업로드 탭에서 학생의 "학년"을 고르세요. 학년에 따라 보고서가 달라집니다.
     · 3학년  → 예상 면접 질문 + 꼬리질문 + 답변 뼈대
     · 1·2학년 → 기록의 빈 곳 + 남은 학기에 보강할 활동 + 과목 선택 조언

  3) [AI 보고서] 탭 →
     ① "보낼 자료 만들기"를 누르면 비식별 처리된 자료가 화면에 뜹니다.
     ② 내용을 직접 눈으로 확인하고, 필요하면 고치세요.
     ③ "AI에게 보내기"를 누르면 그때 전송됩니다.

  보내는 것: 성적 수치, 세특·창체·행특 본문(비식별 처리), 지망 계열·학과
  안 보내는 것: 이름, 학교명, 교사명, 주민번호, 전화번호, 이메일, 주소

  ※ 자동 비식별화는 완벽하지 않습니다. 특이한 대회명·지역명·학교 행사명처럼
    학생을 특정할 수 있는 표현이 남아 있으면 ② 단계에서 직접 지우고 보내세요.
  ※ 1·2학년 보고서는 생기부 기재 금지사항(교외 수상, 공인어학성적, 논문,
    사교육 프로그램 등)을 권하지 않도록 지시해 두었습니다.


■ 학생 개인정보

  · 업로드한 생기부 PDF는 어디로도 전송되지 않습니다.
    브라우저가 파일을 열어 글자만 뽑아낸 뒤, 그 자리에서 분석합니다.
  · 학생 기록은 메모리에만 있다가 앱을 닫으면 사라집니다.
  · 대학 카드, 비식별화 규칙, API 키만 이 브라우저에 저장됩니다.
  · 공용 컴퓨터에서는 끝나고 상단 [기록 지우기]를 눌러 주세요.
  · 외부 AI에 붙여넣을 때는 비식별화가 켜져 있는지 꼭 확인하세요.


■ 폴더 안의 파일

  실행.bat                로컬 실행 (이것만 누르시면 됩니다)
  index.html              앱 본체
  manifest.webmanifest    설치 정보 (앱 이름, 아이콘)
  sw.js                   오프라인 캐시 담당
  server.js / server.ps1  로컬 웹서버 (Node.js 있으면 js, 없으면 ps1)
  vendor/                 PDF 읽기 라이브러리 (pdf.js)
  icons/                  앱 아이콘


■ 다른 선생님께 나눠 드릴 때

  (1) 이 폴더를 통째로 압축해서 전달 → 각자 실행.bat 실행
  (2) 또는 이 폴더를 웹에 올려도 똑같이 동작합니다.
      GitHub Pages, Netlify, Cloudflare Pages 등 HTTPS 주소여야 합니다.
      (설치 기능은 https:// 또는 localhost 에서만 작동합니다.)

      ※ 웹에 올릴 경우 주소를 아는 사람은 누구나 들어올 수 있습니다.
        학생에게 링크를 공유하지 마세요.


■ 알아두실 점

  · 역량 판독은 학종 공통 평가요소(3개 역량·10개 항목, 5개 대학 공동연구 2022) 기준입니다.
    점수는 "평가"가 아니라 성적·기록에서 확인되는 근거의 양입니다.
    낮은 항목 = 학생이 부족하다가 아니라, 면접에서 물어 확인할 곳이라는 뜻입니다.
  · 성적 자동 추출이 어긋나면 [이수·성적 진단] 탭의 표에서 직접 고치면
    진단과 문항에 바로 반영됩니다.
  · 대학별 기출은 프로그램이 지어내지 않습니다.
    각 대학 입학처의 선행학습영향평가 보고서에서 확인한 내용을
    [지원 대학] 탭에 직접 입력해 주세요.
